# TrabalhoFinalAlgoritmoEProgramacao

1. nome do estudante: Evandro Mendonça Pereira Junior
2. nome da disciplina: Algoritmos e Programação
3. título do projeto: TrabalhoAlgoritmo
4. breve descrição do programa: o programa representa um cardapio funcional de uma suposta lanchonete, realizando a coleta do nome do cliente, o pedido e o pagamento
5. principais funcionalidades implementadas: identificação do cliente, cardápio e repetição dos pedidos, seleção de produtos com match/case, validação de quantidade e cálculo do subtotal, cálculo do desconto, forma de pagamento com repetição até opção válida e resumo final
6. instruções necessárias para executar o programa: abra o arquivo no VScode, clique em "run" ou o botao de play e responda o que o programa perguntar.
